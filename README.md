# PiconCockpit (PIC)

![Screenshot](pic1.jpg)

![Screenshot](pic2.jpg)

## Features
PiconCockpit is a plugin for Open Enigma2 receivers that downloads picons from a picon server.

## Limitations
- Supports Enigma2 on OpenViX and compatible distributions only
- Is being tested on DM9xx only
